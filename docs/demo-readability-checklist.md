## 六问测试

| 问题 | 无需原始数据的回答位置 | SC08 / SC07 实查结果 |
|---|---|---|
| 发生了什么？ | 顶部“已经发生”事件摘要 | 事件类型与数量明确 |
| 为什么原方案失效？ | 中文因果链、能力缺口、中文约束表 | 两项中继不足、一条航迹冲突 |
| 哪些任务受到影响？ | 首屏任务集合、因果卡 | 任务 T03/T04/T05 |
| 系统用了哪些技术？ | 七步技术链、四项研究映射、策略卡、算法漏斗 | 方法与页面操作对应 |
| 具体改了什么？ | 实际重构、原方案保留、逐任务对比 | 成员替换和航迹重规划，未改内容单列 |
| 为什么可信、恢复怎样？ | 全局校核、提交语义、恢复结果、限制说明 | 只有合法方案发布，故障事实不变；SC07 失败反馈被保留 |

## 仍需讲解的边界

地图是二维布置图，不是实时飞行动画；平台重叠时仍可能需要点击任务关注或实体详情。底层 API 整次作业返回，没有实时工具进度流，首次失败只能在返回后以历史记录检查。代价向量保留技术详情，不宣称全局最优证明。SC07 为有意构造的诊断场景，不能外推所有场景都优于确定性基线。
